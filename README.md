# 🏝️ Dynamic Island Radio (Tauri)

<p align="center">
  Aplikasi desktop <i>Dynamic Island</i> bergaya futuristik dengan estetika <em>glassmorphism</em> untuk Windows, dilengkapi dengan pemantauan perangkat keras sistem secara <em>real-time</em> dan pemutar audio terintegrasi.
</p>

---

## ✨ Fitur Utama

* **Liquid / Glassmorphism UI**: Antarmuka transparan dengan efek blur, border neon, dan penyesuaian tata letak *notch* yang elegan.
* **Monitor Sistem Lengkap**: Pemantauan performa secara *live* mencakup **CPU**, **RAM**, **GPU**, dan **Ethernet (Jaringan)**.
* **Online Audio Stream**: Pemutar audio terintegrasi untuk mendengarkan siaran radio langsung (seperti Phoenix Radio Bali) dari desktop Anda.
* **Lightweight & Fast**: Dibangun menggunakan kerangka kerja **Tauri (Rust + WebView2)**, memastikan penggunaan memori yang jauh lebih ringan dibanding aplikasi berbasis Electron.
* **Auto-Update via GitHub**: Sistem pembaruan otomatis yang terintegrasi langsung dengan rilis repositori GitHub.

---

## 🛠️ Tumpukan Teknologi (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS dengan kustomisasi gaya modular).
* **Backend**: Rust (`sysinfo` crate, Tauri core APIs).
* **Framework**: Tauri v2

---

## 🚀 Panduan Instalasi (Bagi Pengguna)

1. Unduh berkas installer (`.msi` atau `.exe`) terbaru melalui halaman [GitHub Releases](../../releases).
2. Jalankan pemasang di perangkat Windows Anda.
3. Aplikasi akan berjalan otomatis di bilah atas layar Anda.
