# Third-party sensor library

The Windows sensor helper uses LibreHardwareMonitorLib 0.9.6, licensed under
the Mozilla Public License 2.0 (MPL-2.0). The helper bundles the upstream
library without modifications. The license text is included with the
application as `LibreHardwareMonitor-LICENSE.txt`.

Upstream source: https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
NuGet package: https://www.nuget.org/packages/LibreHardwareMonitorLib/0.9.6

Building the Windows application requires the .NET 8 SDK. The published helper
is self-contained, so users do not need to install .NET separately.
